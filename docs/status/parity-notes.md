# Current parity notes

This list distinguishes deliberate alpha choices from unfinished work. A feature marked **unfinished** is still expected to reach the upstream behavior unless the user later chooses otherwise. No entry proposes changes to Horizon's modding API. See [goal.md](../goal.md) for completion criteria and [handoff.md](../handoff.md) for the latest project snapshot.

## Recording future decisions

For every deliberate simplification, add a row with the upstream behavior, actual alpha behavior, player impact, and reason the pinned modding API prevents a faithful implementation. If the feature is merely unfinished, mark it unfinished instead of calling it an API limitation. Revisit these notes as the implementation changes.
