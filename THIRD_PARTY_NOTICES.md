## Arcforge

Arcforge is created by Zagdrath and is licensed under the MIT License. The upstream license notice is preserved in `LICENSE-Arcforge`. This project adapts Arcforge machine behavior and recipe data for Horizon, including the crushing, carbonizing, infusing, pressing, sifting, fiberizing, Firebox, and Arcforge smelting recipe sets. The Rust implementation translates the machine rules to Horizon's native hooks. The audited source snapshot is `8843cb02cf9132f278f6a8e804b6d78837d3cbcb`. The upstream `src/main/resources/assets/arcforge/` tree from that snapshot is included under `content/assets/arcforge/`; Arcforge's repository README states that Arcforge is released under this MIT License. Existing Horizon-specific files were preserved where paths overlap, and several local additions are not in upstream.
